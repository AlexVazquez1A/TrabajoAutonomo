Inicio

El puente esencial entre el hardware y el usuario

¿Qué es un Sistema Operativo?

Es el software principal que administra el hardware de una computadora y proporciona servicios a los programas de aplicación. Actúa como un intermediario que gestiona recursos como la CPU, la memoria RAM y los dispositivos de entrada/salida.

Funciones Principales

  • Gestión de Procesos: Administra la ejecución de programas en el procesador.
  • Administración de Memoria: Asigna y libera espacio en la memoria RAM para las aplicaciones.
  • Sistema de Archivos: Organiza cómo se almacena y recupera la información en disco.
  • Seguridad y Permisos: Controla el acceso de usuarios y programas a los recursos del sistema.

Sistemas Operativos Populares

Sistema Tipo de Núcleo (Kernel) Uso Principal
Linux Monolítico Servidores, Desarrollo, Supercomputadoras
Windows Híbrido Computadoras personales, Videojuegos
macOS Híbrido (XNU / BSD) Diseño, Edición, Uso general

Comandos Frecuentes en la Terminal

$ uname -a         # Ver información del Kernel

$ top              # Monitor de procesos en tiempo real

$ df -h            # Espacio en disco disponible
